HOW TO REPLACE THE OLD WEBSITE
------------------------------
1. Open your GitHub repository.
2. Rename the repository to: YoussefYousry-21.github.io
3. Delete the old README.txt, styles.css, and script.js.
4. Open the old index.html and delete it OR replace its contents.
5. Upload this new index.html to the repository root.
6. Commit the changes.
7. Open Settings -> Pages.
8. Choose:
   Source: Deploy from a branch
   Branch: main
   Folder: / (root)
9. Save.
10. Wait a minute or two and open:
    https://youssefyousry-21.github.io/
